## 남은 일 · 아이디어 (우선순위 순 아님)

- [ ] 실제 영상을 자동으로 확인하는 기능은 없음. 장면별 조언은 사용자가 실제 영상과 대조할 점검으로 제공.

- [ ] 편집 점검 제안의 효과는 후속 게시물의 같은 통계 시점에서 확인. 인과 효과로 단정하지 않음.

- [ ] D+7 같은 장기 수치 수집: 지금은 D+1·D+2만 있어 글의 수명(언제 조회가 멈추는지)을 모름.
      D+1→D+2 조회 증가 중앙값이 약 1.9배라 D+2에도 아직 크게 늘고 있음
- [ ] 涨粉 그래프에서 광고 팔로워를 쌓아(stacked) 보여주기 — 제안만 하고 미구현
      (지금은 D+2 그래프에 "자연 추정" 점선으로만 표시)
- [ ] 과거 게시물 메모에서 실험 값(썸네일 얼굴·인트로 등)을 추천해 채우기 — 제안만 하고 미구현
- [ ] 채널 상세(此渠道详细数据)를 가진 글이 2~3편 쌓이면 "영상 추천 비중 vs 조회", "실험 vs 영상 추천 시청 시간"
      브리핑이 실제로 나오는지 확인
- [ ] 사용자가 예전 버전으로 저장한 일부 게시물은 OCR 오류가 기록에 남아 있을 수 있음
      (제목·평균 시청 비교값·관심사 등). 사용자가 "D+1/D+2 캡처 다시 올리기"로 고치도록 안내함.
      Supabase 데이터를 직접 고치는 것은 **사용자 동의가 있어야** 함
- [ ] 광고 판단 규칙의 근거 표본이 아직 작음(권장대로 진행한 광고 2건 정도). 기록이 쌓이면 규칙 재점검

## 알려진 한계

- OCR은 작은 숫자·소수점을 놓치기 쉬움. 그래서 여러 교차 검산을 함
  (예: 상호작용 수 = 点赞+评论+收藏 = 互动率 × 观看数, 비율 합 100%, 0/6/8/9 모양 검사).
  확신이 없으면 채우지 않고 "확인 필요"로 표시
- 광고의 "자연 추정"은 주문 보고서 전체 수치를 빼서 계산하므로, 주문이 데이터 마감 뒤까지 이어졌다면
  자연 몫이 실제보다 작게 나올 수 있음(화면에 "추정"으로 표시)
- 비율 지표(클릭률 등)는 광고와 자연을 나눌 수 없음 — 광고 포함 여부만 표시
- 환율은 사용자가 입력한 값만 사용
