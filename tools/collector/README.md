# 小红书 검색 수집기 (읽기 전용)

VLOG Studio의 **검색 근거 추천** 화면에 넣을 자료를 모으는 PC용 작은 프로그램입니다.

- 하는 일: 검색어마다 小红书 검색 결과 상위 노트를 열어 제목, 본문 일부, 해시태그, 좋아요·수집·댓글·공유 수,
  발행 시각(중국 표준시)을 읽고 JSON 파일 하나로 저장합니다.
- 두 목록: 검색어마다 종합(综合, 수집하는 계정 기준이라 개인화가 섞일 수 있음) 결과를 읽은 뒤, 같은 화면에서 '最多点赞'·'半年内' 필터로 한 번 더 읽습니다.
  두 목록에 모두 나온 글이 개인화 영향이 가장 적은 근거입니다. 상세 페이지 수는 그대로이고, 두 목록 모두 → 좋아요 순 → 종합 순으로 엽니다.
- 사람들이 찾는 말: 검색어를 검색창에 입력만 해서(검색하지 않고) 자동완성 목록을 읽고, 결과를 조금 내려 보며 노트와 '大家都在搜' 같은 연관 검색어를 더 읽습니다.
  그래서 검색어마다 몇 초~십몇 초 더 걸립니다. 话题 조회수 읽기는 웹 주소를 확인할 때까지 꺼 두었습니다(`TOPIC_MAX = 0`).
- 하지 않는 일: 게시, 댓글, 좋아요, 팔로우, 표지 이미지 저장, 자동화 숨기기. 다른 서버로 아무것도 보내지 않습니다.
- 표지: 앱의 '검색하기'로 수집할 때만 작게(가로 240px, WebP) 압축해 앱 화면에 한 번 보여 줍니다. 파일·기기·Supabase에는 저장하지 않고, 새로고침하면 사라집니다.
- 로그인 정보: 이 프로그램 전용 Chrome 프로필(`~/.vlog-studio-collector/chrome-profile`)에만 남습니다.
  저장소·앱·Supabase로 가지 않습니다. 지우려면 `logout`.
- 결과 파일: 기본 `private-data/xhs-search/` (git에 올라가지 않는 폴더).
- 페이지에 없는 값은 `null`(미수집)로 저장합니다. 0으로 채우지 않습니다. "1.2万"처럼 줄여 쓴 값은 `approx`에 표시합니다.

## 준비 (처음 한 번)

Python 3.10 이상과 Google Chrome이 필요합니다. 저장소 폴더에서:

```bash
python -m venv .venv
```

Windows: `.venv\Scripts\activate` · macOS/Linux: `source .venv/bin/activate`

```bash
pip install -r tools/collector/requirements.txt
```

Google Chrome이 없으면 추가로 `python -m playwright install chromium`.

## 앱에서 바로 수집 (Windows, 추천)

1. 처음 한 번: `tools/collector/install.bat`을 더블클릭합니다. 필요한 것을 설치하고, 앱이 수집기를 켤 수 있게 등록합니다.
2. VLOG Studio → 더보기 → **검색 근거 추천** → 맨 위 칸에 검색어를 쉼표(,)나 줄바꿈으로 나눠(최대 5개) 넣고 **검색하기**.
3. Chrome이 열지 물으면 "항상 허용"에 체크하고 **열기**. 수집기 창(검은 창)과 수집용 Chrome 창이 뜹니다.
   처음이거나 로그인이 풀렸으면 그 Chrome 창에서 QR을 스캔합니다.
4. 끝나면 결과가 앱에 바로 나옵니다. 파일도 `private-data/xhs-search/`에 남습니다.

- **누를 때만 켜집니다.** 수집기는 30분 동안 요청이 없으면 저절로 꺼지고, 창을 닫으면 바로 꺼집니다.
- 대기 모드는 이 PC 안(`127.0.0.1:47831`)에서만 받고, VLOG Studio 주소에서 온 요청만 처리합니다. 한 번에 하나만 실행합니다.
- 등록을 지우려면 `tools/collector/uninstall.bat`. 휴대폰에서는 쓸 수 없습니다.
- 손으로 켜 두려면: `python tools/collector/xhs_search.py serve`

## 사용 (명령으로 직접)

1. 로그인 (한 번만, 창이 열리면 小红书 앱으로 QR 스캔):

```bash
python tools/collector/xhs_search.py login
```

2. 검색 (검색어 최대 5개, 검색어마다 상세는 기본 8개·최대 10개):

```bash
python tools/collector/xhs_search.py search "海南 新家" "小户型 收纳" --details 8
```

3. VLOG Studio → 더보기 → **검색 근거 추천** → "수집 파일 가져오기"에서 만들어진 JSON 파일을 고릅니다.

## 계정 보호

- 페이지 사이에 몇 초씩 쉬고, 한 번에 검색어 5개·상세 50개를 넘지 않게 막아 두었습니다.
- 小红书가 로그인이나 보안 확인을 요청하거나 접속을 끊으면(연결 끊김·오류 응답) 바로 멈추고 그때까지 읽은 것만 저장합니다. 다시 시도하지 않습니다. 이 경우 몇 시간 쉬었다가 하세요.
- 결과가 전혀 뜨지 않으면(느린 로딩) 검색어마다 한 번만 새로고침합니다. 小红书가 답을 했거나 거절했으면 다시 시도하지 않습니다.
- 파일의 `status`: `empty`는 小红书가 실제로 0개라고 답한 경우, `error`는 읽지 못한 경우(0개라는 뜻이 아님, 이유는 `error`)입니다.
- 파일 이름에 초까지 들어가며, 이미 있는 파일은 덮어쓰지 않습니다.
- 자주, 많이 돌리지 마세요. 내부 화면 구조가 바뀌면 일부 값이 `null`로 나올 수 있습니다.
